# AI Daily Tasks

**AI Daily Tasks** — это современная система для автоматизации сбора командных планов и отчетов через Telegram-бота с AI-генерацией сводок (Gemini), поддержкой мультигрупп, гибким расписанием, историей ответов и удобной админ-панелью.

---

## 🚀 Возможности

- **Мультигрупповая архитектура**: отдельные команды, админы, расписания, уникальные ссылки активации.
- **Telegram-бот**: автоматическая активация, сбор и напоминания, команда `/change` для редактирования ответа.
- **AI-сводка**: генерация отчета по всем ответам через Gemini AI.
- **Гибкое расписание**: настройка времени и дней рассылки для каждой группы.
- **История ответов**: просмотр полной истории каждого участника.
- **Современная админ-панель**: управление пользователями, группами, расписанием, статистика, диагностика.
- **REST API**: для интеграции и расширения.
- **Легкий запуск**: Docker или ручной режим.

## 📦 Быстрый старт

### 1. Клонируйте репозиторий

```bash
git clone <repo_url>
cd AI_daily_tasks
```

### 2. Настройте переменные окружения

Создайте файл `.env` на основе примера:

```bash
cp docker.env.example .env
```

Заполните свои значения:

```env
GEMINI_API_KEY=your_gemini_api_key
TG_BOT_TOKEN=your_telegram_bot_token
ADMIN_ID=your_telegram_user_id
GEMINI_MODEL=gemini-2.5-flash
```

### 3. Запуск через Docker (рекомендуется)

```bash
docker-compose up --build -d
```

- Админ-панель: http://localhost:8501
- API: http://localhost:8000
- Документация API: http://localhost:8000/docs

#### Управление контейнером

```bash
docker-compose logs -f         # Просмотр логов
docker-compose restart         # Перезапуск
docker-compose down            # Остановка и удаление
```

#### Альтернативный запуск через Docker напрямую

```bash
docker build -t ai-daily-tasks .
docker run -d --name ai-daily-tasks -p 8000:8000 -p 8501:8501 -v $(pwd)/data:/app/data --env-file .env ai-daily-tasks
```

### 4. Ручной запуск (без Docker)

```bash
pip install -r requirements.txt
python migrations/init_users.py
python run_all.py
```

- Админ-панель: http://localhost:8501
- API: http://localhost:8000

## 🟢 Как пользоваться системой

### 1. Создайте группу в админ-панели

- Перейдите в http://localhost:8501
- Во вкладке **"Группы"** создайте новую группу, укажите username администратора и настройте расписание.

### 2. Получите ссылку активации

- Для каждой группы генерируется уникальная ссылка вида:
  ```
  https://t.me/aidailytasksBot?start=<group_token>
  ```
- Скопируйте ссылку из админ-панели (вкладка "Группы" → "🔗 Ссылка активации").

### 2.1. Авторизация администратора группы

- После создания группы и указания username администратора, этот пользователь должен:
  - Перейти в Telegram-бота [@aidailytasksBot](https://t.me/aidailytasksBot).
  - Ввести команду `/admin` в чате с ботом.
- Только после этого администратор будет получать AI-сводки, отчёты и сможет управлять своей группой через бота.

---

### 3. Пригласите участников

- Отправьте ссылку участникам вашей команды.
- Участники переходят по ссылке, нажимают `/start` в боте и автоматически активируются в нужной группе.

### 4. Ежедневная работа

- В назначенное время бот отправляет вопросы участникам группы.
- Участники отвечают на вопросы (бот может попросить уточнить слишком короткий или нечеткий ответ).
- Если нужно изменить ответ — используйте команду `/change` в боте.
- Через час после рассылки бот формирует AI-сводку и отправляет её администратору группы.

### 5. Управление и аналитика

- В админ-панели можно:
  - Просматривать и управлять участниками (активация, деактивация, удаление, история ответов).
  - Управлять группами (создание, редактирование, удаление, расписание).
  - Смотреть статистику по активности, процент ответивших, графики.
  - Диагностировать работу планировщика и бота, отправлять тестовые сообщения.

## 🐛 Решение проблем

- **Контейнер не запускается**: проверьте `.env`, логи (`docker-compose logs`), права на папку `data/`.
- **Порты заняты**: измените их в `docker-compose.yml`.
- **Бот не отвечает**: проверьте токен, интернет, логи, статус планировщика в админке.
- **AI-сводка не приходит**: проверьте ключ Gemini, логи, статус администратора.
- **Проблемы с расписанием**: проверьте настройки группы, перезапустите планировщик через админку.
