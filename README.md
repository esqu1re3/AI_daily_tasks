# AI Daily Tasks — Система командных планов через Telegram

Автоматизированная система сбора вечерних планов и отчетов от команд через Telegram-бота с генерацией сводки с помощью Gemini AI. Поддержка нескольких групп, гибкое расписание, история ответов и современная админ-панель.

---

## 🚀 Основные возможности

- **Мультигрупповая система**: Несколько команд с отдельными администраторами, уникальными ссылками активации и независимым расписанием.
- **Telegram-бот**: Автоматическая активация участников, сбор ответов, напоминания, команда /change для редактирования последнего ответа.
- **AI-сводка**: Автоматический анализ и генерация отчета по всем ответам через Gemini AI.
- **Гибкое расписание**: Настройка времени и дней рассылки для каждой группы через админ-панель.
- **История ответов**: Просмотр полной истории ответов каждого участника в админке.
- **Современная админ-панель**: Управление пользователями, группами, расписанием, статистика, диагностика.
- **API**: REST API для интеграции и расширения.

## 📦 Быстрый старт

### 1. Клонируйте репозиторий

```bash
git clone <repo_url>
cd AI_daily_tasks
```

### 2. Настройте переменные окружения

Создайте файл `.env` на основе примера:

```bash
cp docker.env.example .env
```

Заполните свои значения:

```env
GEMINI_API_KEY=your_gemini_api_key
TG_BOT_TOKEN=your_telegram_bot_token
ADMIN_ID=your_telegram_user_id
GEMINI_MODEL=gemini-2.5-flash
```

### 3. Запуск через Docker (рекомендуется)

```bash
docker-compose up --build -d
```

- Админ-панель: http://localhost:8501
- API: http://localhost:8000
- Документация API: http://localhost:8000/docs

### 4. Ручной запуск (без Docker)

```bash
pip install -r requirements.txt
python migrations/init_users.py
python run_all.py
```

## 🏢 Мультигрупповая система

- **Группы**: Каждая команда — отдельная группа с собственным админом, расписанием, участниками и ссылкой активации.
- **Админ**: Управляет только своей группой, получает только свои отчеты.
- **Ссылка активации**: Для каждой группы — уникальная, можно получить в админ-панели.
- **Гибкое расписание**: Для каждой группы настраивается время и дни недели рассылки.

---

## 🤖 Telegram-бот

- **/start** — активация по ссылке, автоматическое добавление в группу.
- **/change** — изменить последний отправленный ответ (если разрешено по времени).
- **/help** — справка.
- **Вечерние вопросы** — бот сам отправляет вопросы по расписанию группы.
- **Постобработка** — если ответ слишком короткий/нечеткий, бот попросит уточнить.

---

## 📝 История ответов

- **Вся история** сохраняется в базе и доступна в админ-панели для каждого пользователя.
- **Пагинация** — просмотр последних 20 ответов, можно расширить через API.
- **Аналитика** — статистика по активности, процент ответивших, графики.

---

## 🎛️ Админ-панель

- **Управление участниками**: активация/деактивация, удаление, просмотр истории ответов.
- **Группы**: создание, редактирование, удаление, настройка расписания, просмотр статистики.
- **Гибкое расписание**: изменение времени и дней рассылки для каждой группы или глобально.
- **Диагностика**: статус планировщика, тестовые сообщения, ручной запуск рассылки.
- **Статистика**: графики активаций, процент ответивших, аналитика по группам.

## 🕐 Как работает расписание

- **Для каждой группы**: индивидуальное время и дни недели рассылки.
- **17:30 (UTC+6)** — пример стандартного времени для группы.
- **Через 1 час** — автоматическая генерация и отправка сводки администратору группы.

## 🆘 Решение проблем

- **Участник не получает сообщения**: проверьте активацию по ссылке, статус в админке, активность пользователя.
- **Сводка не приходит**: проверьте правильность ADMIN_ID, активацию админа, логи Gemini.
- **Бот не запускается**: проверьте токен, переменные окружения, интернет.
- **Проблемы с расписанием**: проверьте настройки группы, перезапустите планировщик через админ-панель.
